# GEO-SMart

GEO-SMart is an interactive model of the Earth system and parametrized climate prediction model. A 3-D globe displays layers from the atmosphere to the inner core. A climate engine calibrated to the IPCC's Sixth Assessment Report (AR6) applies simplified physics to predict the consequences of various climate scenarios. Recognition that 'eventual' drawdowns are hopeful and increasingly unrealistic under capitalist leaders, 'no intervention' scenarios illustrate the necessity of making changes to the way we live and seek profits. Various climate goal pathways, climate sensitivity settings and individualized parameter settings allow predictions from the current year back before the last ice age and thousands of years into the future. The globe and the readouts display and illustrate warming, sea level, ice sheets, sea ice, sea-surface temperature, ocean pH, volcanic eruptions, mantle flow and the magnetic field for that year. The physics logs check the model against observations and the IPCC's assessed ranges. A plain text summary of the Earth's climate as it is set is produced and can be downloaded, along with individual layer physics logs.

Version 6.14.

## Using it

Open `index.html` in a recent version of Chrome, Edge, Firefox or Safari. Your browser needs WebGL, which almost every computer has. The page needs an internet connection the first time it opens, to load three.js, Tailwind, Font Awesome and its Google Fonts. Everything else, including all the maps and data, is inside the file. It is about 13 MB, so it can take a few seconds to open on a slow connection.

## Hosting

`index.html` is a static page. It has no server code and sends nothing anywhere, so it runs on any web host: GitHub Pages, Netlify, or an ordinary web server. To host it, upload it.

The page loads its libraries and fonts from public servers (cdnjs, jsDelivr, the Tailwind CDN and Google Fonts). Those servers see each visitor's IP address, as they do for any site that uses them.
